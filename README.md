# Retina exposome analysis

Analysis code for **An environmental atlas of human retinal anatomy in 55,290 adults**.

This repository contains analysis scripts covering environmental associations, retinal genetic architecture, polygenic and polyexposure scores, gene–exposure interactions, protein mediation, GO enrichment and eye disease associations.

## Analysis modules


| Directory                                         | Analyses                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `exposure_retina_association/`                    | Exposome-wide association, exposure variance explained and association breadth                    |
| `retinal_genetic_architecture/`                   | GWAS, LD clumping, SNP heritability and retinal cell-type enrichment                              |
| `prs_pxs_construction_and_contribution/`          | Independent-exposure selection, PRS/PXS construction and contribution analysis                    |
| `gene_exposure_interaction/`                      | PRS–exposure interactions, vQTL identification and SNP–exposure interactions                      |
| `exposure_protein_retina_mediation/`              | Exposure–protein and protein–retinal associations, bootstrap mediation                            |
| `mediation_protein_go_enrichment/`                | GO biological process enrichment and semantic reduction                                           |
| `eye_disease_association_and_prs_stratification/` | Retinal-trait and PRS associations with eye disease, PRS-stratified exposure–disease associations |
